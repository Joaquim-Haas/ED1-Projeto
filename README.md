# Sistema da cidade Inteligente

Um sistema feito em linguagem C para simular o monitoramento de uma cidade inteligente usando somente alocação dinâmica. Sendo esse sistema, um projeto da disciplina de Estrutura de Dados 1 da UTFPR.

## Tecnologias

* Linguagem C;
* Git para versionamento.
